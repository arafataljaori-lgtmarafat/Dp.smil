# ADR-006 — Immutable Source Media

**الحالة:** مقبول في Phase 0.

## السياق

تتضمن المنصة صور وجه وأسنان حساسة، وقد يختلط الناتج المولد مع الأصل إذا جرى الاستبدال أو التحديث في مكانه.

## القرار

تقسم الأصول إلى `SOURCE` و`DERIVED` و`GENERATED`. لا يمكن الكتابة فوق الأصل ولا استبداله بعد المعالجة؛ كل تحويل ينشئ `MediaAsset` جديدًا بخط نسب واضح.

## السبب

يحافظ ذلك على النزاهة وإثبات الأصل وإمكانية المراجعة، ويمنع تقديم ناتج توليدي كأنه صورة مريض أصلية.

## النتائج

يزيد عدد الكائنات المخزنة، ولذلك تحتاج المراحل اللاحقة إلى سياسة احتفاظ وحذف تستوعب الرسوم البيانية للوسائط بدل الحذف الساذج.

## البدائل

رُفضت أعمدة «before/after» القابلة للاستبدال، ورُفض تخزين ناتج التوليد في نفس مفتاح الملف المصدر.
