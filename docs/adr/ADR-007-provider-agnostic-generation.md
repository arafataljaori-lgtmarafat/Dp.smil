# ADR-007 — Provider-Agnostic Generation

**الحالة:** مقبول في Phase 0.

## السياق

اختيار أول API لتوليد صورة لا يجب أن يحدد معمارية المنتج أو يحتكر بياناته وتدفقه.

## القرار

تعرف طبقة التطبيق `SmileSimulationProviderPort` بمدخلات ومخرجات محايدة. يوجد في Phase 1 مزود وهمي حتمي فقط، ولا توجد مطالبات أو أسماء نماذج أو عناوين مورّد أو مفاتيح داخل كيانات المجال.

## السبب

يمكن لاحقًا مقارنة مزودين وتغييرهما وتحسين التحقق من النتائج من دون تغيير مسار الوظيفة أو التطبيق المحمول.

## النتائج

يتطلب كل مزود محولًا صريحًا وبيانات أصل/إصدار مسجلة، ويمنع اختصار الشاشة إلى استدعاء SDK مباشر.

## البدائل

رُفض ربط شاشة الهاتف بخدمة توليد، ورُفض تضمين تفاصيل مزود بعينه ضمن `GenerationJob` خارج مفتاح مزود وإصداره المقصودين للإثبات.
