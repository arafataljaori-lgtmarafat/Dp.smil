# ADR-025: بايتات مصدر غير قابلة للتغيير ومعالجة مشتقة مستقبلية

## السياق

سلامة المصدر وإعادة إنتاج التوليد تتطلبان أن تشير تجزئة SHA-256 المخزنة وسجل المنشأ إلى البايتات نفسها التي التزم بها الرفع. إعادة ضغط المصدر أو تدويره أو إزالة EXIF أو تحويل ألوانه في المكان تقطع هذه العلاقة.

## القرار

تظل بايتات المصدر المتحقق منها والمخزنة ككائن `MediaAsset` من النوع `source` غير قابلة للتغيير. لا تعيد Phase 3A ترميز المصدر أو تطبيعه أو تدويره أو تغيير ألوانه أو إزالة EXIF منه. تحسب DentPilot SHA-256 مستقلًا للبايتات ولا تستبدله بـ S3 ETag.

## السبب

يؤمن ذلك رابطًا ثابتًا بين سجل الوسائط والبايتات ومصدر وظائف التوليد وإصدارات النتائج. وتبقى دقة السلامة مستقلة عن اختلاف دلالات ETag في التحميل متعدد الأجزاء أو بين الموفرين المتوافقين مع S3.

## النتائج

أي إدخال قانوني للذكاء الاصطناعي أو نسخة خصوصية أو معاينة مصغرة أو إزالة بيانات وصفية مستقبلية ينشأ كـ `derived` منفصل مع منشأ صريح، ولا يعدل المصدر. لا تدعي المرحلة دعم HEIC أو HEIF أو GIF أو SVG أو TIFF أو RAW؛ يبقى عقد الإدخال الحالي JPEG وPNG وWebP حتى يختبر الدعم في وقت التشغيل.

## البدائل المدروسة

رُفضت معالجة المصدر في المكان لأنها تغيّر التجزئة والسجل التاريخي. ورُفض استخدام ETag كدليل سلامة لأنه ليس تجزئة SHA-256 مستقرة لمحتوى DentPilot عبر جميع أنماط S3.
