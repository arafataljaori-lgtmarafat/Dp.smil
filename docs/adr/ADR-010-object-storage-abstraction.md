# ADR-010 — Object Storage Abstraction

**الحالة:** مقبول في Phase 0.

## السياق

الصور ملفات ثنائية حساسة ولا ينبغي أن تديرها قاعدة البيانات أو أن يسمح العميل بتحديد مساراتها أو درجة إتاحتها.

## القرار

تعرف طبقة التطبيق `ObjectStoragePort` بعمليات `put/get/delete/exists`. يستخدم Phase 1 محولًا محليًا، ويقبل فقط مفاتيح بنمط خادمي مولد ويرفض عبور المسار والكتابة فوق كائن موجود.

## السبب

يبقي القرار التطبيق محايدًا تجاه S3 أو مزود متوافق أو تخزين محلي، ويمنع تسرب أسماء ملفات العميل ومسارات نظام الملفات إلى الواجهة.

## النتائج

يتطلب كل محول مستقبلي تشفيرًا وسياسات وصول خاصة وروابط موقعة أو بثًا مصرحًا به. لا يشكل المحول المحلي دليل امتثال أو حلًا سحابيًا إنتاجيًا.

## البدائل

رُفض استخدام أسماء ملفات العميل كمفاتيح، ورُفض كشف مسار ملف محلي أو جعل كائنات المرضى عامة.
