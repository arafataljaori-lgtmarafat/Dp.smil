# ADR-003 — Modular Backend Architecture

**الحالة:** مقبول في Phase 0.

## السياق

لا يجوز أن يصبح مزود AI أو التخزين أو HTTP هو معمارية المنتج، ولا أن تنتشر قواعد العمل داخل المتحكمات.

## القرار

يستخدم API NestJS/Fastify كطبقة نقل فقط. توجد الخدمات في `packages/application` والقواعد في `packages/domain`. تتعامل البنية مع منافذ مثل التخزين والطابور والمزود والمستودع.

## السبب

يتيح هذا استبدال مزود أو طابور أو تخزين من دون إعادة كتابة دورة الحالة أو إثبات الأصل.

## النتائج

تحتاج التركيبة إلى حقن تبعيات واضح ومحولات أكثر من نموذج CRUD المباشر، لكنها تمنع اقترانًا يصعب فكه لاحقًا.

## البدائل

رُفض وضع منطق التوليد داخل متحكم HTTP أو داخل مكونات React، ورُفض ربط SDK خاص بمزود داخل كيانات المجال.
