# ADR-002 — React Native + Expo Mobile Client

**الحالة:** مقبول في Phase 0.

## السياق

المنتج موجه في الأساس لهواتف الأطباء والعيادات، ويحتاج تنقلًا مكتوب الأنواع واختيار وسائط وحالات شبكة واضحة.

## القرار

يعتمد العميل React Native مع Expo وExpo Router. تستخدم الشاشات عميل API مركزيًا وعقودًا مشتركة، ولا تتصل بمزود AI أو بقاعدة البيانات.

## السبب

يوفر Expo دورة تطوير مناسبة للهواتف، بينما يحافظ Expo Router على تنقل ملفي قابل للكتابة والاختبار.

## النتائج

يبقى الخادم مرجع الحالة والملكية. يجب ألا توضع عناوين API أو منطق المجال في المكونات، وتبقى حالة الشبكة مرئية وقابلة لإعادة المحاولة.

## البدائل

رُفض تطبيق ويب فقط لأنه لا يطابق هدف الهاتف، ورُفضت مناداة AI من التطبيق لأنها تتجاوز الأمن والإديمبوتنسية والتدقيق.
