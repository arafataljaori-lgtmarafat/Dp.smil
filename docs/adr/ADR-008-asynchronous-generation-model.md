# ADR-008 — Asynchronous Generation Model

**الحالة:** مقبول في Phase 0.

## السياق

التوليد المستقبلي قد يطول أو يفشل أو يعاد، ولا يصح تمثيله كاستجابة HTTP متزامنة من الشاشة إلى مزود.

## القرار

يمثل التوليد `GenerationJob` بحالات صريحة ومفتاح إديمبوتنسية. يرسل التطبيق إلى `GenerationQueuePort`؛ في Phase 1 ينفذه محول ذاكرة للتطوير، ويمكن لاحقًا استبداله بطابور دائم.

## السبب

يوفر ذلك عرض تقدم صحيحًا، وإعادة محاولة آمنة، وعزلًا بين HTTP وعمل المزود، وانتقالات قابلة للاختبار.

## النتائج

طابور الذاكرة ليس صالحًا للإنتاج ولا يبقى بعد إعادة تشغيل API. يلزم Phase إنتاجي لعامل دائم وسياسة استرداد للوظائف العالقة.

## البدائل

رُفض انتظار مزود التوليد ضمن طلب HTTP طويل، ورُفض تمثيل النجاح بزر هاتف معطل فقط.
