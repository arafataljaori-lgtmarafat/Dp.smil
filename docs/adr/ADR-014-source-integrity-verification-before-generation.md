# ADR-014 — Source Integrity Verification Before Generation

**الحالة:** مقبول في Phase 1.1.

## السياق

تخزين SHA-256 وقت الرفع لا يكفي إذا تغير الكائن في التخزين لاحقًا.

## القرار

قبل استدعاء المزود، يقرأ العامل بايتات الوسيط المصدر ويحسب SHA-256 ويقارنه بالقيمة المحفوظة. يوقف الاختلاف التوليد بكود `SOURCE_INTEGRITY_MISMATCH`، ولا يستدعي المزود أو يحدث checksum أو ينشئ ناتجًا.

## السبب

يجعل الأصل غير القابل للتعديل خاصية تستخدم عند القرار الحساس، لا معلومة وصفية خاملة.

## النتائج

تضاف قراءة وتجزئة قبل التوليد. يسجل الفشل بصورة آمنة في حالة الوظيفة والتدقيق، فيما يبقى السبب الداخلي للتسجيل المنظم فقط.

## البدائل المدروسة

رُفض الوثوق بchecksum المخزن دون إعادة تحقق، ورُفض تصحيح checksum تلقائيًا، ورُفض تمرير الصورة إلى المزود عند ظهور اختلاف.
