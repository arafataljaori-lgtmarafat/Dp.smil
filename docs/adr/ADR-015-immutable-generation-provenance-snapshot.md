# ADR-015 — Immutable Generation Provenance Snapshot

**الحالة:** مقبول في Phase 1.1.

## السياق

اسم المزود وإصدار النتيجة وحدهما لا يجيبان عن المصدر أو عقد الطلب أو المعلمات الفعلية لناتج تاريخي.

## القرار

تخزن `GenerationVersion` حقولًا مستقلة غير قابلة للتحديث: `sourceMediaId` و`sourceSha256` و`providerKey` و`providerVersion` و`generationContractVersion` و`mediaAssetId` و`versionNumber`، مع JSONB للمعلمات المحايدة القابلة للتمديد فقط.

## السبب

يوفر ذلك استرجاعًا تاريخيًا ودليل أصل واضحًا عند تغير المزود أو عقد المنتج لاحقًا، من دون كشف تفاصيل المزود الخاصة في DTO الهاتف.

## النتائج

لا يوجد منفذ تحديث لنسخة التوليد. ينشئ كل ناتج نسخة جديدة في معاملة واحدة تشمل الأصل والتدقيق وإنهاء الوظيفة.

## البدائل المدروسة

رُفض حقل `latestResult` قابل للكتابة، ورُفض تخزين الإثبات كله في JSON مبهم أو خارج السجل الدائم.
