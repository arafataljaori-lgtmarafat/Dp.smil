# ADR-004 — PostgreSQL System of Record

**الحالة:** مقبول في Phase 0.

## السياق

تتطلب الملكية متعددة العيادات والإديمبوتنسية والإصدارات والتدقيق علاقات وقيودًا ومعاملات قوية.

## القرار

PostgreSQL هو سجل النظام؛ يستخدم API Prisma ومخططًا مترحلًا من الصفر. تخزن البيانات الثنائية في تخزين كائنات، لا في أعمدة PostgreSQL.

## السبب

يوفر PostgreSQL مفاتيح خارجية وقيودًا فريدة وفهارس ومعاملات لتنفيذ صحة لا تعتمد على تعطيل زر في الهاتف.

## النتائج

يلزم تشغيل قاعدة بيانات محلية وترحيلها قبل API، ويلزم أن تكون الاستعلامات مقيدة بالعيادة ومستخدمة للفهارس المحددة.

## البدائل

رُفض التخزين داخل JSON غير العلاقي لإخفاء التصميم، ورُفض حفظ الصور الثنائية في الجداول.
