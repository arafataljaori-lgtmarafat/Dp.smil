# DentPilot Smile Studio — تقرير تنفيذ Phase 3A

**التاريخ:** 2026-08-27  
**النتيجة:** **PHASE 3A COMPLETE — READY FOR SECURE MEDIA INGEST IMPLEMENTATION**

## 1. بنية التخزين المنفذة

أصبحت قاعدة البيانات سجل الملكية وحالة الاستيعاب، بينما التخزين مخزن كتل خاص فقط. يختار `OBJECT_STORAGE_DRIVER` محول `local` للتطوير والاختبار أو محول `s3` المتوافق مع AWS S3 وMinIO. مفاتيح المصدر والمخرجات والتجهيز منشأة مركزيًا من الخادم ولا تدخل ضمن عقود العميل.

## 2. تغييرات `ObjectStoragePort`

استُبدل عقد البايتات بـ `putStream` و`getStream` و`head` و`delete` و`probeReadiness`. يعيد `getStream` تدفقًا وبيانات وصفية آمنة فقط: الحجم والنوع وETag عند وجوده. لا يستخدم النظام ETag لإثبات سلامة SHA-256. أضيف `collectStreamWithinLimit` كجسر توافق مركزي محدود لمسار التوليد الوهمي والقراءة القديمة؛ لم تُبعثر عمليات التحويل إلى ذاكرة.

| المحول | النتيجة |
|---|---|
| `LocalObjectStorageAdapter` | يدعم التدفقات والبيانات الوصفية والحذف وفحص الجاهزية، ويرفض المفاتيح خارج مساحة أسماء الخادم أو التي تحاول الخروج من الجذر. |
| `S3ObjectStorageAdapter` | يستخدم AWS SDK v3، ويدعم AWS S3 وMinIO والموفرين المتوافقين، ولا يضبط ACL عامًا ولا ينشئ URL أو حاوية. |
| MinIO | نجح اختبار العقد الفعلي: كتابة تدفق، `head`، قراءة تدفق، حذف، بيانات وصفية، ورفض مفتاح traversal. |

## 3. الإعدادات والنشر

أضيفت إعدادات S3 المركزية و`MEDIA_STREAM_COLLECTION_MAX_BYTES` و`MEDIA_UPLOAD_SESSION_TTL_SECONDS`. يرفض الإنتاج `OBJECT_STORAGE_DRIVER=local` ويرفض تكوين S3 الناقص؛ فلا يوجد رجوع صامت للتخزين المحلي. يفحص التشغيل الإنتاجي اتصال الحاوية عبر `HeadBucket` من دون إنشائها. يوضح `.env.example` ضرورة حجب الوصول العام وتفعيل التشفير الساكن لدى مزود التخزين، مع إمكانية إعداد تشفير S3 اختياريًا.

## 4. نموذج `MediaUploadSession` وآلة الحالات

أضيفت جلسة دائمة مملوكة للمستخدم والحالة بالحالات `created` و`processing` و`committed` و`failed` و`expired`. يفرض PostgreSQL أشكال الحالات الصحيحة ومدة الانتهاء ومفتاح الإديمبوتنسية غير الفارغ. يرتبط `(ownerUserId, caseId)` بالحالة عبر مفتاح مركب، ويرتبط `committedMediaId` عند وجوده بوسيط المستخدم والحالة نفسيهما.

**الترحيل:** `20260827130000_phase_3a_durable_media_upload_sessions`.

| الضمان | التنفيذ |
|---|---|
| الإديمبوتنسية | فهرس فريد على `(ownerUserId, caseId, idempotencyKey)` وإنشاء `INSERT ... ON CONFLICT DO NOTHING RETURNING` ثم قراءة السجل الموجود ضمن معاملة سليمة. |
| الانتقالات | منفذ مخصص لـ `claimForProcessing` و`markCommitted` و`markFailed` و`markExpired` و`listStale`، بلا `update()` عام. |
| مفتاح الإحاطة | تنشأ المطالبة رمز معالجة خادمًا؛ تتطلب عمليات الالتزام أو الفشل الحالة `processing` والرمز المطابق في شرط UPDATE الذري. |
| منع الالتزام المتقادم | انتقال الانتهاء أو الفشل يغير الحالة نهائيًا، فلا يستطيع طلب برمز سابق الالتزام لاحقًا. |

## 5. قرارات البنية

أضيفت ADR-022 إلى ADR-025 لتوثيق حد S3 الخاص، والرفع عبر API قبل الروابط الموقعة، وآلة حالات جلسة الرفع، وثبات بايتات المصدر والمعالجة المشتقة المستقبلية.

## 7. الأوامر المنفذة

نفذت أوامر التثبيت والتدقيق وفحص الأنواع والاختبارات والبناء، إضافة إلى `prisma migrate deploy` و`prisma validate` و`prisma migrate diff --exit-code` على قاعدة جديدة ومسار ترقية، واختبارات العقد المحلية وMinIO وجلسات الرفع. يضيف CI خدمة PostgreSQL وخطوة MinIO صريحة قبل اختبار S3، فلا تتخطى بوابات S3 أو PostgreSQL المطلوبة بصمت.

## 8. الحدود المتبقية المقصودة

لا توجد عيوب مانعة معروفة في نطاق Phase 3A. ما يزال متحكم الوسائط القائم يقرأ multipart كاملًا عبر `toBuffer()`، وتبقى قراءة المحتوى الحالية جمعًا محدودًا للتدفق؛ هذان **جسران مقصودان** إلى Phase 3B، التي ستضيف الاستيعاب المتدفق والتحقق/الإنهاء. لم تُضف Phase 3A نقاط HTTP جديدة أو روابط S3 موقعة أو تحميلًا مباشرًا أو دعم صيغ جديدة أو معالجة مشتقة أو ذكاءً اصطناعيًا أو تغيرات في UX.
