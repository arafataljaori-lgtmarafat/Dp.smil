# تقرير تصحيح ملكية المستخدم — DentPilot Smile Studio

**الحالة:** منجز ضمن التصحيح الإلزامي قبل Phase 2.  
**حد النطاق:** لم تبدأ المصادقة ولا Phase 2، ولم تضاف ميزات منتج جديدة.

## المفاهيم المحذوفة

أزيلت من النموذج النشط جداول `clinics` و`clinic_memberships` ونوع `ClinicRole` وحقول `clinicId` وأدوار وعضويات العيادة. لا توجد طبقات `Workspace` أو `Organization` أو `Team` بديلة. يملك المستخدم الشخصي البيانات مباشرة.

## نموذج الملكية الجديد

كل من `PatientCase` و`MediaAsset` و`CreationProject` و`GenerationJob` و`GenerationVersion` و`AuditEvent` يحمل `ownerUserId`. يمرر سياق الممثل هذا المعرف إلى خدمات التطبيق والمستودعات والطابور. يحمل الممثل النظامي `ownerUserId` صريحًا عند معالجة رسالة توليد، ولا توجد هوية مستخدم عامة مفترضة.

## الترحيل وbackfill

أضيف ترحيل مستقل: `20260826200000_personal_user_ownership`. يضيف أعمدة `ownerUserId` أولًا، ثم يقرر المالك من `ClinicMembership` السابق فقط إذا كان لكل عيادة membership واحدة تمامًا. يفشل الترحيل مغلقًا عند وجود عضوية معدومة أو متعددة أو بيانات لم يمكن إسنادها. بعد backfill، ينشئ قيود المستخدم والمفاتيح المركبة، ويحذف أعمدة العيادة والعضويات وجداول العيادة ونوع الدور.

## قيود PostgreSQL

أعيدت كل قيود Phase 1.1 و1.2 المركبة بصيغة المستخدم:

```text
(ownerUserId, parentId) → (ownerUserId, id)
```

تغطي القيود الحالات والوسائط وlineage الوسائط والمشروعات ووظائف التوليد والنسخ وأحداث التدقيق. لا يستطيع مستخدم A ربط أي من هذه الكيانات بكيان يملكه مستخدم B. نطاق الإديمبوتنسية هو `(ownerUserId, projectId, idempotencyKey)`.

## الطابور والإديمبوتنسية

تغيرت رسالة الطابور إلى `{ schemaVersion, jobId, ownerUserId, correlationId }`. يتحقق العامل من تطابق مالك الرسالة والوظيفة قبل المطالبة بالوظيفة. استمرت حماية البصمة والإديمبوتنسية والادعاء الذري وSHA-256 والتنظيف التعويضي دون تخفيف.

## الاختبارات المحولة

استبدلت اختبارات tenancy باسمين واضحين: `user-isolation.persistence.test.ts` و`user-ownership-constraints.test.ts`. تثبت هذه الاختبارات أن مستخدم A لا يستطيع قراءة حالة مستخدم B أو إنشاء مراجع Case/Media/Project/Job/Version/Audit أو lineage متقاطعة. استمر اختبار سباق الإديمبوتنسية وclaim الذري، كما استمرت اختبارات التطبيق لسلامة المصدر وتصنيف الفشل والتنظيف عند فشل الاستمرارية.
