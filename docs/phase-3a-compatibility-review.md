# تقرير استعادة المستودع وخط أساس Phase 2

**التاريخ:** 2026-08-27  
**النطاق:** استعادة المستودع الكامل من مرجع Phase 2B الأقدم، مع إبقاء النسخة الأحدث هي مصدر الحقيقة لكل ملف مشترك وتأكيد عدم بدء Phase 3A.

## قرار الدمج

اعتُمدت النسخة الأحدث كمصدر الحقيقة. استُخدم أرشيف `dentpilot-smile-phase-2b(1).gz` لاستعادة المسارات الغائبة فقط؛ لم يُستبدل أي ملف مصدر موجود في النسخة الأحدث. أُعيدت نسختا `pnpm-workspace.yaml` و`pnpm-lock.yaml` المقفلتان من المرجع بعد أن أنشأ فحص محلي سابق ملفي مساحة عمل/قفل غير مكتملين في نسخة العمل، وهي ملفات لم تكن موجودة أصلاً في الأرشيف الأحدث.

| بند الاستعادة | النتيجة |
|---|---|
| ملفات مرجع Phase 2B | 165 ملفًا مفهرسًا |
| ملفات النسخة الأحدث قبل الاستعادة | 88 ملفًا |
| مسارات كانت غائبة واستُعيدت فقط | 89 مسارًا |
| ملفات حصرية للنسخة الأحدث حُفظت | 12 ملفًا |
| ملفات مشتركة مختلفة بين الإصدارين | 16 ملفًا؛ بقيت النسخة الأحدث لجميع ملفات المصدر المشتركة |
| مساحات العمل | استُعيدت حزم API وMobile وDomain وApplication وContracts، إضافةً إلى `pnpm-workspace.yaml` و`pnpm-lock.yaml` |

## التعديلات الحديثة المحفوظة

احتُفظ دون استبدال بترحيل `20260827120000_phase_2_security_closure` واختبارات تعطيل الحساب وسباقات كلمة المرور وسكربت قبول تعطيل الحساب وتقرير وADR إغلاق الأمان. كما احتُفظ بملفات حماية معاينة الويب (`WEB_DEPLOYMENT.md`، و`netlify.toml`، و`public/_redirects`، واختبار `web-preview-safety.test.ts`) وبالملفات المشتركة الأحدث الخاصة بالمخطط والمصادقة والجلسات والعميل المتنقل.

## إصلاح استعادة محدود

كان برنامج التهيئة الموجود في المرجع يستورد `src/common/development-actor.js`، لكن ملف المصدر المقابل لم يكن موجودًا في أي من الأرشيفين. أُضيف الملف المفقود فقط، وفيه هوية تطوير حتمية تستخدم المعرف `00000000-0000-4000-8000-000000000001` الموثق في ترحيل Phase 2A.1. يقتصر هذا الثابت على تهيئة التطوير؛ ملكية الطلبات وقت التشغيل تظل مشتقة من جلسة Bearer المصادَق عليها.
